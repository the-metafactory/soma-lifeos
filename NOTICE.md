# PAI / LifeOS notice

This pack ports skills from Daniel Miessler's PAI, published as LifeOS, in the upstream repository
[`danielmiessler/PAI`](https://github.com/danielmiessler/PAI). Each member's `arc-manifest.yaml`
carries an `upstream:` block naming the path and the full commit it was ported from.
Skills that came over in the 2026-06-12 migration of `~/.claude/skills` pin to commit
`2fde1bbe9e8f280cd4998e244b53e3c66f3dc8b9` (2026-05-21, `Packs/<Name>/src`); skills ported
from LifeOS 8.761.0 pin to `fb9aef4640a73feae4c2e6483b26f58491ce2665`.
